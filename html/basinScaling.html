Basin analysis

shLowLevel.basinScaling

Leakage/attenuation scaling factors by forward modelling.

Syntax

[k, info] = shLowLevel.basinScaling(op, b, tsModel);            % tvANS op
[k, info] = shLowLevel.basinScaling(W, b, tsModel, idx=idx, tYears=ep);  % matrix

Description

The classic gain-factor approach: push a model series through the SAME operator as the data and regress true against filtered basin averages, k = Σatrueafilt/Σafilt². Scaled series: k·(b′xfilt)/(b′b). Operators: tvANS struct, static P×P matrix (Gaussian/DDK/fan), or function handle. INFO carries sigmaK and per-month factors (PerMonth=true) so the model-dependence assumption is checkable. Complements basinDeconvolve (operator inversion on a kernel set) with the literature-standard scaling route.

k depends on the MODEL's spatial pattern inside and around the basin. Quote k with its model dependence, or use two models and report the spread.
