Data management

Data folder, DDK family, ICGEM access (v2.4.1)

One persistent storage location, all released DDK filters, and the ICGEM model catalogue.

shLowLevel.dataFolder

shLowLevel.dataFolder("D:/geodata/shAnalysis")   % set once, persists across sessions
shLowLevel.dataFolder()                    % query (default: <toolbox>/data)
shLowLevel.dataFolder("reset")

All fetchers store beneath it: itsg_series/, DDK/, icgem/. Point it at a shared network folder to reuse downloads across machines.

shLowLevel.fetchDDK / shLowLevel.readDDK("DDK<n>")

shLowLevel.fetchDDK(1:8);                  % ~10 MB each, skips existing
W5 = shLowLevel.readDDK("DDK5");           % name resolution against dataFolder
gF = g.applyDDK(W5);

All eight released filters (Kusche 2007; Kusche et al. 2009), strong → weak: DDK1 (a=1e14) … DDK8 (5e9); regularization a·l⁴. DDK3 ships inside the toolbox and never needs fetching; an unfetched name errors with the fetch hint (shLowLevel:readDDK:notFetched). Filenames come from one mapping (shLowLevel.ddkNames), verified against the repository.

shLowLevel.listICGEM / shLowLevel.fetchICGEM

T = shLowLevel.listICGEM();                        % 180+ static models: name,
sortrows(T, 'year', 'descend')              % year, degree, data, url
f = shLowLevel.fetchICGEM("EGM2008");              % -> dataFolder/icgem/*.gfc
g = shCoefficients.read(f);

The static catalogue is parsed from icgem.gfz.de/tom_longtime (parser fixture-tested offline against a saved page). Name resolution: exact match, else unique prefix; ambiguity errors with candidates. Type="temporal" (reworked v2.4.2) returns the full temporal catalogue parsed from the series-page links of /sl/temporal — every series of every center (~70+ across the groups 01_GRACE, 02_COST-G, 03_other, 04_SLR) with columns group, center, series, path, url (series page) and zip (whole-series ZIP, hundreds of MB). Passing a catalogue path into Series= lists the individual files of that series (name, url) — single monthly .gfc files download directly via websave; the earlier "JavaScript-only" caveat is obsolete. Example:

T = shLowLevel.listICGEM(Type="temporal");             % 70+ series, all centers
F = shLowLevel.listICGEM(Type="temporal", ...
        Series="03_other/ITSG/ITSG-Grace2018/monthly");
websave("m1.gfc", F.url(1));                    % one monthly file

For ITSG monthly files shLowLevel.fetchITSG remains the convenient route, whose default target is dataFolder/itsg_series.
