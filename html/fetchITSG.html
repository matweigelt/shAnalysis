I/O

shLowLevel.fetchITSG / shSeries.fromFolder

On-demand download of real ITSG monthly solutions and folder loading.

Syntax

[files, info] = shLowLevel.fetchITSG(2010:2016);        % whole years, monthly
shLowLevel.fetchITSG(["2008-04","2010-11"], Nmax=60);   % single months
shLowLevel.fetchITSG("2008-04", Product="daily");       % daily Kalman, n40
ts = shSeries.fromFolder(info.dest, Truncate=60);

Description

Daily product (v2.4.1): the ITSG daily Kalman-smoother solutions - one ICGEM .gfc per day (~83 kB, n40 only, formal errors, zero_tide), released for both ITSG-Grace2018 and the operational GRACE-FO series. The months/years spec expands to all days (a year is ~365 files, ~30 MB); target dataFolder/itsg_daily, kept separate from the monthly series so fromFolder never mixes samplings. Filename epochs (mid-day decimal year) parse automatically.

websave (base MATLAB) from ftp.tugraz.at/pub/ITSG/GRACE with automatic release routing (ITSG-Grace2018 before the mission gap, ITSG-Grace_operational from 2018-06). Existing files are skipped; nonexistent months (gap 2017-07..2018-05, dropouts) land in info.missing instead of erroring. Default target tests/test_data/itsg_series — once populated with ≥ 24 months, demo cases D05/D06 switch to real data automatically. Cite the ITSG release (Mayer-Gürr et al.) when publishing.
