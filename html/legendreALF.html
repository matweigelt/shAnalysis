Core / Legendre functions

legendreALF

Compute fully normalized (4-pi, ICGEM convention) associated Legendre functions Pbar_nm(sin(lat)) for a set of latitudes, using the stable Holmes & Featherstone (2002) forward-column recursion.

Syntax

P = legendreALF(nmax, lat)

Description

legendreALF is the numerical core shared by shSynthesis and by shSpectralCrossover-adjacent diagnostics. It returns fully normalized associated Legendre functions consistent with the ICGEM / GRACE Stokes-coefficient convention, i.e. the convention in which ∫∫ [Pbar_nm(sinφ)cos(mλ)]2 dΩ = 4π over the unit sphere.

The recursion is stable without rescaling for nmax up to several hundred, which covers every current GRACE, GRACE-FO, GOCE, or EGM-class product (nmax ≤ 300 in practice). It is not intended for extreme-degree work (nmax in the thousands), where extended-range arithmetic would be required.

This function is a low-level building block. Most users will call shSynthesis directly, which calls legendreALF internally (and can reuse a precomputed P across a time series via its 'P' option).

Input Arguments

ArgumentDescription
nmaxMaximum spherical harmonic degree to compute (non-negative integer).
latGeocentric latitude(s) in radians, scalar or vector.

Output Arguments

ArgumentDescription
P(nmax+1) x (nmax+1) x numel(lat) array. P(n+1,m+1,k) = Pbar_n,m(sin(lat(k))) for n≥m; the upper triangle (m>n) is zero.

v2.1: scaled recursion to degree 2190

The engine now uses the scaled forward-column recursion of Holmes & Featherstone (2002): the uᵐ factor of each column is carried separately with a 1e-280 scale factor, keeping the recursion overflow/underflow-free up to at least degree 2190 (EGM2008/XGM2019e) at all latitudes. Cross-validated in Python: agreement with the plain recursion to 8.4e-15 at nmax=120; addition-theorem sum rule Σm Pbar² = 2n+1 satisfied to 3e-11 relative at n = 2190, lat = 89.99°.

Examples

Basic evaluation at a few latitudes

lat = deg2rad([-90 -45 0 45 90]);
P = legendreALF(10, lat);
size(P)   % 11 x 11 x 5

Computes Pbar_nm up to degree 10 at five latitudes. Index (n+1,m+1,k) picks out a specific degree/order/latitude combination, e.g. P(3,1,3) is Pbar_2,0 at the equator.

Checking the 4-pi normalization

nodes = linspace(-1,1,2000)';
lat = asin(nodes);
P = legendreALF(20, lat);
Pbar_5_2 = squeeze(P(6,3,:));
% integral of Pbar_5_2^2 over the sphere (with cos(m*lambda) part) should equal 4*pi

A quick sanity check useful when validating any downstream change to this function -- see validate_sh.py for the full independent Python cross-check (orthonormality to 8e-14).
