Spectral domain / plotting

plotSHSpectrum

Log-log degree-amplitude spectrum plot, with support for overlaying several spectra (e.g. successive months, or signal vs. formal error).

Syntax

plotSHSpectrum(spec)
plotSHSpectrum({spec1, spec2, ...}, 'names', {'a','b',...})

Description

Plots spec.degree against a chosen field (default degAmplitude) on a log-log scale. This is the standard visualization for interpreting a shDegreeRMS result: a smoothly decaying line is dominated by real signal; a spectrum that flattens or turns upward at high degree is dominated by noise (see the Getting Started guide / accompanying PDF for annotated examples).

Input Arguments

ArgumentDescription
specsA single spec struct (from shDegreeRMS), or a cell array of specs to overlay.
'names'Cell array of legend labels, one per spec.
'units''mm' (default) or 'm' for the y-axis.
'field'Which spec field to plot, default 'degAmplitude'; also accepts 'errAmplitude' to plot the error spectrum.
'ax'Axes handle to plot into (default: new figure).

Output Arguments

ArgumentDescription
hVector of line handles, one per spectrum plotted.

Examples

Single spectrum

spec = shDegreeRMS(dC, dS, 'R', R, 'n0', 2);
plotSHSpectrum(spec);

Quick look at one month's degree-amplitude spectrum.

Signal vs. error overlay

spec = shDegreeRMS(dC, dS, 'R', R, 'n0', 2, 'sigmaC', sigC, 'sigmaS', sigS);
plotSHSpectrum({spec, spec}, 'names', {'signal','error'}, 'field', 'degAmplitude'); % first trace
hold on;
plotSHSpectrum(spec, 'field', 'errAmplitude', 'ax', gca, 'names', {'error'});

Overlaying signal and error spectra makes the crossover degree visually obvious -- compare against the numeric value from shSpectralCrossover.

Comparing several months

plotSHSpectrum({spec_jan, spec_feb, spec_mar}, 'names', {'Jan','Feb','Mar'});

Useful for spotting months with anomalous high-degree power (often a sign of a bad solution or unusually strong striping that month).
