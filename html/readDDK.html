shLowLevel.readDDK / shLowLevel.applyDDK

DDK (Kusche) anisotropic decorrelation filters: load and apply.

Syntax

W  = shLowLevel.readDDK('ddk4.mat')        % converted container (recommended)
W  = shLowLevel.readDDK('ddk4.txt')        % documented ASCII exchange format
gF = g.applyDDK(W);  tsF = ts.applyDDK(W);
[Cf, Sf] = shLowLevel.applyDDK(C, S, W);   % low-level

Description

The DDK filters (Kusche 2007; Kusche et al. 2009; DDK1–DDK8) are the standard published anisotropic alternative to Gaussian smoothing: within each (order m, C/S) block a full matrix over degrees replaces the scalar Gaussian weight. Container: W.nmax, W.blocks(m, cs, n, M), W.name. Degrees not covered pass through unchanged; a filter reaching beyond the coefficients’ nmax raises shLowLevel:applyDDK:nmaxMismatch.

Native binary support (v2.2.1): the released Wbd_* files (Rietbroek/Kusche BIN format, strawpants/GRACE-filter, MIT) parse directly — endian autodetect, versions 2.1 and ≥ 2.4, verified against the repository-documented pack values of Wbd_2-120.a_1d12p_4 (DDK3) to 4.4e-16; that file ships in tests/test_data. Mapping: DDK1=a_1d14p_4, DDK2=1d13, DDK3=1d12, DDK4=5d11, DDK5=1d11, DDK6=5d10, DDK7=1d10, DDK8=5d9. Use Nmax=96 to truncate an Lmax-120 filter for n96 series (leading submatrices, reference-consistent). The .mat container and ASCII exchange formats remain supported.

Sigma handling

applyDDK invalidates formal errors (NaN / dropped) — the filter correlates coefficients. Propagate uncertainties through the filter with shLowLevel.mcPropagate.
