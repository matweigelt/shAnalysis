shx.readLoveNumbers

Read load Love numbers from a user-supplied table. The toolbox never hardcodes Love numbers — this reader turns YOUR loading-model table (PREM, Gutenberg-Bullen, ak135, ...) into the kn/hn/ln vectors that EWH synthesis and elastic deformation expect.

Syntax

LN = shx.readLoveNumbers(file)
[LN, info] = shx.readLoveNumbers(file, Columns="n h l k", ...
        MaxDegree=96, Interp="pchip", InFrame="CE", OutFrame="CF")

Recognized layouts

layouthandling
2 columnsassumed [n kn] (documented default)
3+ columns with headermapped by header tokens n/degree, k(n)('), h(n)('), l(n)(') — commented headers (# n h' l' k') recognized
3+ columns, no headerrefused as ambiguous (classic Farrell tables order h l k, others k h l): pass Columns= explicitly

Comment lines (%, #, !, //), csv/semicolon separators and unordered rows are handled.

Sparse tables (Interp)

Farrell-style tables list only n = ..., 32, 56, 100, ... With MaxDegree= the coverage of 0..MaxDegree is verified; gaps error unless Interp="pchip" fills them by shape-preserving interpolation in log(1+n). Python-validated: maximum absolute error 1.3e-4 (0.05% of the curve range) reconstructing a smooth k'n curve from 15 Farrell-spaced samples. Extrapolation beyond the table span errors. info.interpolated flags the filled degrees.

Degree-1 reference frames (InFrame/OutFrame)

Degree-1 load Love numbers depend on the origin of the reference frame (Blewitt 2003, isomorphic frames): h1, l1, k1 all shift by the same constant d when the origin changes.

conversionshift d (computed from the input values)
CE → CF(h1 + 2 l1) / 3
CE → CM1 + k1
CF → CM1 + k1
CM → CF(h1 + 2 l1) / 3
CF/CM → CErefused (not recoverable from the table alone)

Validated against the published PREM values: CE (−0.290, 0.113, 0.021) → CF (−0.269, 0.134); the identity k1(CM) = −1 holds exactly; the CF→CM→CF roundtrip is exact.

Use ONE consistent loading model for all three sets, and match the frame to your GRACE degree-1 handling (TN-13 is CF) before comparing with GNSS loading series.

Example (G7 GNSS chain)

LN = shx.readLoveNumbers("prem_load.txt", Columns="n h l k", ...
         MaxDegree=96, Interp="pchip", InFrame="CE", OutFrame="CF");
[up, no, ea] = g.deformation(lat, lon, kn=LN.kn, hn=LN.hn, ...
         ln=LN.ln, Mode="points");
