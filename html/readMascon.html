I/O

shx.readMascon

Read JPL / CSR / GSFC mascon netCDF grids for comparison against the SH chain.

Syntax

mas = shx.readMascon('GRCTellus.JPL.200204_202512.GLO.RL06.1M.MSCNv03CRI.nc')

Description

Base-MATLAB ncread-based reader with auto-detection of the common variable layouts (lwe_thickness / lwe / water_thickness; lat/latitude; lon/longitude; time with “days since” units → decimal years). Returns lat (nlat,1), lon (nlon,1, 0..360), epoch (T,1) decimal years, ewh (nlat,nlon,T) as stored (check mas.units), units, name.

Latitude convention: mascon grids are typically geodetic. Synthesize SH fields on the mascon grid with LatType="geodetic" (or convert via shx.geodetic2geocentric) before differencing — skipping this biases mid-latitudes by up to ~21 km of latitude. Full comparison workflow: guide, “Comparing against mascons”.
