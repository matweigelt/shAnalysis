Functionv2.1

readSINEX

Read gravity-field SINEX files (ITSG, COST-G, ...): parameter estimates, covariance matrices and normal equations — e.g. to feed a released full covariance into the tvANS filter via opts.NoiseCov.

Syntax

snx = shx.readSINEX(filename)                          % .snx or .gz
snx = shx.readSINEX(f, Output="covariance")            % invert an NEQ (Cholesky)
snx = shx.readSINEX(f, Index=shx.shIndex(60))          % reorder to idx, row for row
[tsF, op] = ts.filter("tvANS", NoiseCov = snx.M);      % downstream use

Parsed blocks

BlockContent
+SOLUTION/ESTIMATEparameter list: type CN/SN, degree, order, value, formal sigma
+SOLUTION/MATRIX_ESTIMATE L|U COVAcovariance (lower/upper triangle, up to 3 values per line, symmetrized)
+SOLUTION/NORMAL_EQUATION_MATRIX L|Unormal-equation matrix; inverted to a covariance with Output="covariance" (errors shx:readSINEX:neqNotPD if not positive definite)

Outputs

FieldDescription
n, m, cs(Q,1) parameter list (cs: 0=C, 1=S), file order or Index order
x, sig(Q,1) estimates and formal sigmas
M(Q,Q) symmetric covariance or NEQ ([] if absent)
kind'COVA' | 'NEQ' | ''
Verified against real data. The parser was validated against a real ITSG-Grace2018 n96 monthly SINEX (TU Graz): the actual layout is CN  2 --  0  08:107:00000 ---- 2  value  std — CODE = degree, SOLN = order, PT = '--'. Degree/order are therefore taken as the first integer token after CN/SN and the next integer ≤ degree, which also covers plain "CN n m ... value std" layouts. A truncated real fixture (first 12 parameters + the consistent 12×12 NEQ principal submatrix, values verbatim) ships in tests/test_data/ITSG-Grace2018_n96_2008-04_head12.snx and is covered by the robustness suite incl. Cholesky inversion against independently computed sigmas. Matrix indices beyond the parameter list error with shx:readSINEX:badMatrixIndex. The reader loads the whole file into memory — fine for monthly solutions to Lmax ~ 120, not tuned for the full 440-MB n96 NEQ archives.
