Processing

removeGIA (shSeries / shClimatology)

Glacial isostatic adjustment correction — the missing step before every trend map.

Syntax

gia = shCoefficients.read('ICE-6G_D_Stokes_trend.gfc');   % rate [1/yr]
ts2 = ts.removeGIA(gia);                 % subtract rate*(t - T0) per epoch
cl2 = ts.climatology().removeGIA(gia);   % or correct the fitted trend

Description

Secular trends in GRACE/GRACE-FO Stokes coefficients mix present-day mass change with the solid-Earth GIA signal. Both routes above are exactly consistent for the trend (tested to 1e-13): subtracting the linear model from the series, or subtracting the rate coefficients from the fitted trend. Models are ALWAYS user-supplied gfc files — never embedded.

Honest accounting: the model is treated as exact; its uncertainty (often the dominant regional trend error over Laurentia, Fennoscandia, Antarctica) is not propagated. Best practice: difference several GIA models (ICE-6G_D, Caron, A/W13) as a spread estimate — see the guide.
