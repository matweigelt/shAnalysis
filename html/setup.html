setup_shAnalysis

One-call setup: adds the toolbox to the MATLAB path (temporarily or permanently) and orchestrates the data downloads in cumulative levels. Re-running is idempotent — existing files are skipped, every download is verified by parse before it is accepted, and an offline machine still gets a working path setup plus the shipped fixtures.

Syntax

setup_shAnalysis                        % path, this session only
setup_shAnalysis(Permanent = true)      % path + savepath
setup_shAnalysis(Download = "core")     % + TN-14/TN-13 (~250 KB)
setup_shAnalysis(Download = "filters", DDK = [2 3 5])
setup_shAnalysis(Download = "starter")  % + ITSG starter months
s = setup_shAnalysis(DryRun = true, Download = "starter")   % plan only

Download levels (cumulative)

leveladdssizebackend
"none"path only (default)——
"core"GSFC TN-14 (C20/C30) + TN-13 geocenter files (GFZ/CSR/JPL) — the low-degree completion chain~250 KBshx.fetchTN
"filters"anisotropic DDK decorrelation matrices (subset via DDK=, default 3)~10 MB eachshx.fetchDDK
"starter"ITSG monthly-solution starter set (default: the n96 companions of the shipped n60 fixture months, 2008-04 and 2025-12)~1 MB/monthshx.fetchITSG

Downloads land in shx.dataFolder() subfolders (TN/, DDK/, itsg_series/). Point shx.dataFolder(PATH) at a shared location first to reuse downloads across machines.

Path handling

Already-on-path is detected (no duplicate entries). With Permanent=true, savepath persists the path; if that fails (no write permission on pathdef.m — common on managed machines) the session path stays set and a warning explains the startup.m alternative.

Verification & failure handling

shx.fetchTN parses every file with shx.readTN13/readTN14 before accepting it — a truncated download or an HTML error page never survives (deleted + reported). Each level runs in isolation: failures are collected in summary.failed and the remaining levels still run. summary.ok is true iff nothing failed.

DryRun

DryRun=true returns the full action plan with zero side effects: no path change, no folder creation, no network. Contract-tested.
