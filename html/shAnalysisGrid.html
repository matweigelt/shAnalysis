Functionv2.1

shAnalysisGrid

Spherical harmonic analysis: estimate Stokes coefficients from gridded or scattered data — the inverse of shSynthesis. User-facing entry point: shCoefficients.analysis(...); the core is shx.shAnalysisGrid.

Syntax

[C, S, info] = shx.shAnalysisGrid(grid, latVec, lonVec, nmax)
[C, S, info] = shx.shAnalysisGrid(..., Method="auto"|"rings"|"ls", quantity=..., ...
                                  Weights="none"|"coslat", Kaula=0, kn=..., GM=..., R=...)
g = shCoefficients.analysis(grid, latVec, lonVec, nmax, ...)   % returns an shCoefficients

Two data layouts (auto-detected)

LayoutMethodProperties
Ring grid: grid is nlat×nlon, lonVec uniform covering the full circle (any latitude spacing: equiangular, Gauss-Legendre, irregular rings) "rings" Longitude is diagonalized by FFT; one small least-squares problem per order over the latitude rings. For band-limited data with enough rings (> nmax−m per order) and nlon > 2·nmax this is exact — round-trip validated to 8.7e-15, including non-zero start longitude, cos-latitude weighting and quantity kernels (1.4e-22 in the literal-port check). Fast: O(nlat·nlon·log nlon + nmax³) instead of a dense (nlat·nlon)×(nmax+1)² system.
Scattered points: grid, latVec, lonVec equal-length vectors "ls" Full least squares on (nmax+1)² unknowns; normal equations accumulated in chunks (ChunkSize=2000), Cholesky solve with conditioning guards. Exact for sufficient sampling (validated 6.4e-15).

Key options

OptionMeaning
quantity'geoid' (default) | 'potential' | 'gravity_anomaly' | 'gravity_disturbance' | 'ewh'. The degree-dependent kernel (shx.kernelFactors, the same single source used by synthesis) is divided out so C, S are Stokes coefficients. Degrees with zero kernel (n = 0, 1 for gravity anomaly) are unobservable, returned as 0 and listed in info.unobservedDegrees. 'ewh' requires user-supplied load Love numbers kn (never hardcoded).
Weights"coslat" applies sqrt(cos lat) row scaling (diagonal area-weight approximation); recommended for redundant noisy equiangular grids. For complete ring systems the solution is weight-independent.
Kaula> 0 enables Tikhonov regularization toward 0 with per-degree sigma Kaula·1e-5/n² (Kaula's rule; 1 = classic). Required when the sampling underdetermines the coefficients — without it, rank deficiency raises shx:shAnalysisGrid:rankDeficient instead of returning leakage-contaminated numbers silently.

Outputs

NameType / sizeDescription
C, S(nmax+1)×(nmax+1) doubleStokes coefficients, C(n+1,m+1); S(:,1) always 0
infostructmethod, nPoints, residRMS (post-fit, grid units; Parseval-exact for rings), condEst, unobservedDegrees, regularized
Regional grids. Analysis of an incomplete/regional grid is ill-posed: expect leakage across degrees unless Kaula regularization is used or nmax is restricted to what the sampling supports. Sn0 does not exist (sin 0 = 0) and is always returned 0.

Example

% round trip: synthesize a band-limited EWH field, recover the coefficients
lat = linspace(-89, 89, 180);  lon = 0:2:358;
grid = g.synthesis(lat, lon, quantity="ewh", kn=kn);
gHat = shCoefficients.analysis(grid, lat, lon, 60, quantity="ewh", kn=kn, ...
                               GM=g.GM, R=g.R);
max(abs(gHat.C - g.C), [], 'all')          % ~1e-15 relative

% scattered altimetry-style points with Kaula stabilization
gS = shCoefficients.analysis(vals, latPts, lonPts, 30, Kaula=1);
