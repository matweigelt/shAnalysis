Filtering

shDestripe

Remove correlated north-south striping noise from Stokes coefficients (Swenson & Wahr 2006).

Syntax

[Cf, Sf] = shDestripe(C, S)
[Cf, Sf] = shDestripe(C, S, 'minOrder', m0, 'polyOrder', p, 'windowLength', w)

Description

At each order m ≥ minOrder, splits the coefficients into even-degree and odd-degree subsequences (correlated GRACE errors alias into that parity split) and removes a low-order polynomial fit in degree n from each. By default this is a single polynomial fit over the whole available degree range per order/parity (the original Swenson & Wahr formulation); setting 'windowLength' switches to a centered moving-window fit (the "P3M6"-style variant, polyOrder=3, windowLength=6 being a common choice from Duan et al. 2009).

Cross-checked (validate_destripe.py): a synthetic pure quadratic-in-degree trend is absorbed to <1e-13 residual by the order-2 polynomial fit, confirming the filter removes exactly the class of smooth-in-degree trend it targets.

Input Arguments

ArgumentDescription
C, SStokes coefficient matrices to destripe.
'minOrder'Lowest order to filter, default 6. Below this, real signal dominates and destriping mostly removes signal -- verify against your own signal-vs-error spectrum (shDegreeRMS/shSpectralCrossover) rather than trusting the default blindly.
'polyOrder'Polynomial order fit and removed per order/parity, default 3.
'windowLength'If empty (default), fit one polynomial over the full series. If an odd integer ≥ polyOrder+2, use a centered moving window of that length instead.

Output Arguments

ArgumentDescription
Cf, SfDestriped coefficient matrices, same size as input.

Examples

Classic (whole-series) destriping

[dCf, dSf] = shDestripe(dC, dS, 'minOrder', 6, 'polyOrder', 3);

Good default for a first look; check the coefficient triangle (plotSHCoeffTriangle) before/after.

Moving-window ('P3M6'-style) destriping

[dCf, dSf] = shDestripe(dC, dS, 'minOrder', 6, 'polyOrder', 3, 'windowLength', 6);

Tends to preserve more real signal at the transition orders than the whole-series fit, at some cost in stripe-removal strength -- compare both against your specific noise characteristics.
