I/O

shEvalGFCT

Evaluate time-variable Stokes coefficients C(t), S(t) at a specific epoch from a gfct-type model read by shReadGFC.

Syntax

[Ct, St] = shEvalGFCT(model, epoch)

Description

Reconstructs C(t) = C0 + trnd·(t-t0) + ∑k [acos_k·cos(2π(t-t0)) + asin_k·sin(2π(t-t0))], and analogously for S(t), from model.C/model.S (the constant part) and model.variableTerms.

Assumption: acos/asin terms are treated as annual (period = 1, same units as epoch/t0). This matches the common ICGEM gfct convention but is not universal -- check model.variableTerms(:).type and your model's own documentation, especially if it defines additional sub-annual terms under other tags.
If model.variableTerms is empty (a static file was read), this function returns the constant C, S unchanged and issues a warning.

Input Arguments

ArgumentDescription
modelStruct from shReadGFC with a non-empty variableTerms field.
epochEvaluation epoch, same units/convention as the t0 values in the file (typically decimal year).

Output Arguments

ArgumentDescription
Ct, St(nmax+1)x(nmax+1) coefficient matrices evaluated at epoch.

Examples

Evaluate a time-variable model at a chosen epoch

model = shReadGFC('EIGEN-6C4-timevariable.gfct');
[Ct, St] = shEvalGFCT(model, 2015.5);

Ct, St can be fed directly into shDegreeRMS or shSynthesis like any other coefficient set.
