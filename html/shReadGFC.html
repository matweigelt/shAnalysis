I/O

shReadGFC

Read an ICGEM ASCII gravity field model file (.gfc, .gfct, or gzip-compressed .gfc.gz / .gfct.gz) into Stokes coefficient matrices and metadata.

Syntax

model = shReadGFC(filename)

Description

Parses the ICGEM header (key:value pairs up to end_of_head) and the coefficient block. Supports both plain static models (gfc records) and time-variable models (gfct records plus trnd/acos/asin term records). Gzip-compressed files are decompressed to a temporary directory automatically and cleaned up afterward.

GM and R fall back to GRACE-era constants (3.986004415e14, 6378136.3) only if the header does not provide them -- always check model.header if you need to confirm what was actually read from the file.

Input Arguments

ArgumentDescription
filenamePath to a .gfc, .gfct, .gfc.gz, or .gfct.gz file.

Output Arguments

ArgumentDescription
model.GMGravitational parameter [m^3/s^2] (from the header, or a GRACE-era fallback if absent).
model.RReference radius [m].
model.nmaxMaximum degree found in the file.
model.C, model.S(nmax+1)x(nmax+1) coefficient matrices, C(n+1,m+1), lower-triangular.
model.sigmaC, model.sigmaSFormal errors, same layout (NaN where not given).
model.headerStruct of all raw header key:value pairs.
model.variableTermsStruct array of trnd/acos/asin records (empty for static models) -- see shEvalGFCT.
model.modelnameModel name string, if present in the header.

v2.1: ICGEM format 2.0

Files with format icgem2.0 in the header are fully supported: piecewise gfct validity intervals (all pieces are stored in variableTerms; C/S expose the most recent piece), per-term [t0, t1) activity windows on trnd/acos/asin lines, explicit period columns, and yyyymmdd(.hhmm) epochs converted to decimal years (shx.icgemDate2Year). shEvalGFCT evaluates the correct piece per epoch and errors with shEvalGFCT:epochOutside beyond the covered range. ICGEM 1.0 behavior is preserved; note one documented change: an 8-column acos/asin line is now read as EIGEN-style “period in the last column” (with the reference epoch taken from the matching gfct line), while ≥9-column lines keep the pre-v2.1 t0/t1 reading.

Examples

Reading a static model

m = shReadGFC('EGM2008.gfc');
fprintf('GM=%.6e, R=%.3f, nmax=%d\n', m.GM, m.R, m.nmax);

Standard static field, e.g. a mean gravity field or geoid model.

Reading a GRACE-FO monthly solution and forming an anomaly

m1 = shReadGFC('GSM-2_202401.gfc');
m2 = shReadGFC('GSM-2_202402.gfc');
dC = m2.C - m1.C;
dS = m2.S - m1.S;

Monthly gravity-change coefficients, the standard input to the spectral/spatial analysis chain (see the shAnalysis workflow overview).

Reading a gzip-compressed file directly

m = shReadGFC('GSM-2_202401.gfc.gz');

No manual decompression needed -- handled transparently.
