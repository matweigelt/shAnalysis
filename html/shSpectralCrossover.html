Spectral domain

shSpectralCrossover

Find the degree at which the error spectrum first exceeds the signal (degree-amplitude) spectrum -- a principled guide for choosing a truncation degree or Gaussian filter radius.

Syntax

[nCrossover, degreeInterp] = shSpectralCrossover(spec)

Description

Requires spec to include both degAmplitude and errAmplitude (i.e. produced by shDegreeRMS called with sigmaC/sigmaS). Returns the first integer degree where error exceeds signal, plus a sub-degree estimate via log-space linear interpolation between that degree and the one before it -- more useful in practice for tuning a smooth filter radius than the integer value alone.

Returns NaN/NaN if the error spectrum never exceeds the signal spectrum over the available degree range -- this can legitimately happen for very well-determined low-degree static fields.

Input Arguments

ArgumentDescription
specStruct from shDegreeRMS with both degAmplitude and errAmplitude fields.

Output Arguments

ArgumentDescription
nCrossoverFirst integer degree where errAmplitude > degAmplitude. NaN if no crossing occurs.
degreeInterpSub-degree (real-valued) interpolated crossover estimate. NaN if no crossing occurs.

Examples

Finding a data-driven filter radius

spec = shDegreeRMS(dC, dS, 'R', R, 'n0', 2, 'sigmaC', sigC, 'sigmaS', sigS);
[nX, nXi] = shSpectralCrossover(spec);
fprintf('crossover near degree %.1f -- consider truncating there or filtering to suppress it\n', nXi);

A common rule of thumb is to choose a Gaussian filter radius whose weight function (shGaussianWeights) has dropped substantially by nXi, rather than truncating hard (which introduces ringing).
