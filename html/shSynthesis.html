Spatial domain

shSynthesis

Synthesize a global or regional lat/lon grid (geoid height, gravity anomaly, gravity disturbance, disturbing potential, or equivalent water height) from Stokes coefficients.

Syntax

[grid, lat, lon] = shSynthesis(C, S, GM, R, latVec, lonVec)
[grid, lat, lon, P] = shSynthesis(..., 'quantity', q, 'nmin', n1, 'nmax', n2)
grid = shSynthesis(..., 'P', P)   % reuse precomputed Legendre functions

Description

Performs the spatial-domain reconstruction f(φ,λ) = ∑n kernel(n) ∑m Pbar_nm(sinφ) [Cnm cos(mλ) + Snm sin(mλ)], with a quantity-dependent degree kernel (see table below).

quantitykernel(n)units
geoid (default)Rm
potentialGM/Rm^2/s^2
gravity_anomaly(GM/R^2)·(n-1)m/s^2
gravity_disturbance(GM/R^2)·(n+1)m/s^2
ewh(R·ρ_ave)/(3ρ_water) · (2n+1)/(1+k_n)m (water equiv.)
surface_density (v2.3)(R·ρ_ave)/3 · (2n+1)/(1+k_n)kg/m²
bottom_pressure (v2.3)g₀ · surface_density kernel, g₀ = GM/R²Pa
deformation_up (v2.3)R · h'_n/(1+k'_n) — elastic vertical load deformation (horizontals: shSynthesisDeformation)m
gravity_gradient_rr (v2.3)(GM/R³)(n+1)(n+2) — T_rr; 1 Eötvös = 1e-9 s⁻²1/s²
EWH synthesis intentionally does not ship a built-in Love number table -- pass 'kn' explicitly from a validated source (e.g. a PREM-based table, Wahr et al. 1998 / Han & Wahr) rather than relying on unverified hardcoded constants.
Runtime is loop-based over degree and latitude; fine for typical GRACE-FO monthly nmax (60-96). For very high-resolution static fields (nmax > 200) at fine grid spacing, a Clenshaw-summation rewrite would be faster if this becomes a bottleneck.

Input Arguments

ArgumentDescription
C, S(nmax+1)x(nmax+1) fully normalized Stokes coefficient matrices.
GM, RGravitational parameter [m^3/s^2] and reference radius [m] (from shReadGFC, typically).
latVec, lonVecGrid latitude/longitude vectors in degrees.
'quantity''geoid' (default) | 'gravity_anomaly' | 'gravity_disturbance' | 'potential' | 'ewh' | 'surface_density' | 'bottom_pressure' | 'deformation_up' | 'gravity_gradient_rr' (v2.3).
'nmin', 'nmax'Degree range to include. Default 0 and size(C,1)-1.
'kn'Load Love numbers k'_n (required for 'ewh', 'surface_density', 'bottom_pressure', 'deformation_up'; NOT hardcoded -- must be supplied explicitly, see Notes).
'hn' (v2.3)Load Love numbers h'_n ('deformation_up' only; user-supplied).
'Height' (v2.3)Evaluation height above R [m]: upward-continuation attenuation (R/r)^p for potential-type quantities (p = n+1 potential, n+2 anomaly/disturbance, n+3 T_rr); surface quantities reject it.
'rho_ave', 'rho_water'Densities used for 'ewh', default 5517 and 1000 kg/m^3.
'P'Precomputed Legendre array from a prior call, to skip the recursion (see Examples).

Output Arguments

ArgumentDescription
gridnumel(latVec) x numel(lonVec) synthesized quantity.
lat, lonRow vectors of the grid coordinates actually used (degrees).
PPrecomputed Legendre array, for reuse in a subsequent call (see batch example).

v2.1: fast paths

'method': 'auto' (default) | 'direct' | 'fft'. On a uniform full-circle longitude grid the per-order sums are accumulated into FFT bins (mod nlon, exact even when orders alias) and inverse-transformed — validated against the direct sum to 2.9e-13; typically 5–20× faster at 1° resolution. Symmetric latitude grids additionally reuse the Legendre recursion for ±lat pairs via the parity relation Pbarnm(−φ) = (−1)ⁿ⁺ᵐ Pbarnm(φ) (exact). The internal restructuring to per-order sums also speeds up the direct path (one BLAS product instead of a per-degree loop).

Examples

Synthesizing a geoid-change map from monthly GRACE-FO coefficients

[N, lat, lon] = shSynthesis(dCg, dSg, m1.GM, m1.R, -90:1:90, 0:1:359, ...
                             'quantity', 'geoid', 'nmax', 60);
imagesc(lon, lat, N*1000); set(gca,'YDir','normal'); colorbar; % mm

dCg/dSg would typically already be destriped and Gaussian-smoothed (see shDestripe, shGaussianFilter).

Batch time series reusing precomputed Legendre functions

lat = -90:1:90; lon = 0:1:359;
[grid1, ~, ~, P] = shSynthesis(dC1, dS1, GM, R, lat, lon, 'nmax', 60);
for k = 2:nMonths
    grids(:,:,k) = shSynthesis(dCk{k}, dSk{k}, GM, R, lat, lon, 'nmax', 60, 'P', P);
end

P depends only on latVec and nmax, not on the coefficients -- computing it once for a fixed grid and reusing it across all months in a time series skips the Legendre recursion entirely on every subsequent call.
